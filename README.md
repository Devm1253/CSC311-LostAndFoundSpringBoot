# Campus Lost & Found

**Student:** Dev Mondal

## Run the app

1. Install Java 21 and Maven.
2. From the project directory, run `mvn spring-boot:run`.
3. Open [http://localhost:8080](http://localhost:8080), register an account, and sign in.

The app stores users and found items in the local H2 database. The H2 console is available at `/h2-console` while the app is running.
